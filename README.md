# Game gia đình

Bộ game chơi chung một máy (lần lượt từng người), chạy trên trình duyệt, cài được lên điện thoại và chơi không cần mạng.

| Game | Trạng thái |
|---|---|
| 🥐 Đế chế Tiệm Bánh (`01_DE_CHE_TIEM_BANH/docs`) | Chơi được |
| ♟️ Chiến thuật ô cờ | Sắp có |
| 🧭 Thám hiểm mê cung hợp sức | Sắp có |

Kiểm thử bộ máy game: `cd 01_DE_CHE_TIEM_BANH && npm test`
Mô phỏng cân bằng: `npm run mophong`
